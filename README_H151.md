# V191-H151｜主管 Excel 分類工作表正式修復

## 目的

原本 `00_主管重點觀察榜` 在第 7 頁的 Excel 匯出流程中，被依序追加 H148.3 具名研究、H149 六維分析、H148.2 來源稽核與隔離明細。這不是凍結視窗可以正確處理的單一表格：有多組獨立表頭、篩選範圍、資料格式，且使用者難以搜尋。

H151 將各資料類別輸出到獨立 **Excel 工作表（仍然是一個 .xlsx 檔案）**，不刪除分類資料、不改股神決策、不重算候選、不改 H109/H113/H123/H124/H126 授權。

## 部署

本 ZIP 為**一次覆蓋用的 H150+H151 累積修復包**：只複製 ZIP 原有相對路徑到實際 GitHub `main` 專案根目錄，先比對版本差異，再提交。禁止直接以本專案 H146 舊完整 ZIP 覆蓋目前 GitHub。此次 ZIP 不包含 JSON 推薦紀錄、使用者設定、Secrets 或 runtime-data；程式修改也不會寫入這些資料。

部署前後可執行：

```bash
python tools/h151_verify_deploy.py --root .
python -m pytest -q tests/test_h151_excel_split.py tests/test_h151_deploy.py
```

部署後到第 7 頁重新按「建立主管研究 Excel」，確認下載為 `StockPick_H151_SplitSheets_*.xlsx`、工作表共 12 張、主管榜表尾不再有附錄、每個分類各自能篩選，以及 `00_H126主管決策` 在第二張且值完全一致。Streamlit 如使用快取，需重新產生一次報表而非使用上一次的下載快取。正式 Cloud 部署與真實資料匯出仍須現場驗收。
