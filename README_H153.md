# V191-H153 | 成長價值 × 預發動技術 × 可參考股票同分並列排名

**基準：** 使用者 H146 完整程式 `stock-app-main(1).zip` + H152.1 累積修改。此 ZIP 是可從 H146 一次覆蓋的 **H147～H153 累積程式包**，不是完整資料備份，也不負責清除或寫入使用者權威資料。

## 核心修正

1. `godpick_h114_parallel_alpha.analyze_history()` 使用**本輪日期以前已存在的日 K 線**，新增 MA5/20 與 MA20/60 黃金交叉確認、先前 20 日箱頂/箱底、箱型準突破/突破/假突破及技術失效條件。K 線不足、成交量單位未知，不會產生已驗證型態。
2. `godpick_h153_growth_setup_rank.py` 從 H148.3 同輪**完整診斷池**而非 H113 限量 120 檔中尋找符合流動性和技術條件的研究候選。只使用 H114 同日 ≥60 根有效 K、當日與 20 日平均成交額各≥150百萬、成交量≥500張、量比≥0.55 等證據，不以舊 H110 同分/股票代碼取得虛假名次。
3. 官方基本面**只**經 `godpick_h115_pit_evidence.build_h114_evidence` 截至研究日的公告可用時間帳本進入 H114 月營收／EPS／PE 估值評估。按年增、三月營收成長、近12月公告新高、同業 PE 折價獨立標記；缺來源不給基本面加分。正 EPS 不直接等於「同業高 EPS」。不借用未證實的 legacy 現時快取。
4. 新增下月營收**模型情境**：僅在具有 24 個連續已公告、已核對來源的逐月數據時，按最近三月 YOY 中位數與去年同月基準估算，呈現是否「可能」創高。此值不是公司財測、不是已公布營收，也**不得加研究分**；尚無樣本外校準、沒有漲幅預測保證。
5. `01_具名強勢研究` 左側加入 **研究排名、等級、研究證據分、基本面、技術型態及反證**。A（已核成長＋技術）優先、B（量價技術）其次、C（保留 H109 否決之反證）排後；同等級／同分並列，如 1、1、3。股票代碼僅用於穩定顯示。舊研究線索仍保留在下方，未核實者**不給研究名次**。
6. `03_五檔研究計畫` 接續前五位具名研究候選，保留原 H149 有效價位計畫；若沒有同日支撐與壓力證據，明列**不可估算參考風險報酬**，不產生虛假目標或停損價。`00_主管重點觀察榜` 摘要提示前五名研究代號。`02_研究召回統計` 增加各排除原因。

## 不變的約束

- 原有 **12 張工作表、4 個重點彩色頁籤、H151.2 OOXML 凍結視窗修復**全部保留。
- `00_H126主管決策` 仍是**第 2 張**，H109/H113/H123/H124/H126 權威與風控規則不變。A/B/C **只是研究優先序，不代表正式買進或明日上漲機率**。
- H150 登入自動更新、H152 逆勢抗跌、H152.1 預發動研究、既有紀錄／設定都不更動。
- 不新增官方 API 請求，不把使用者今日的財報資訊倒灌到歷史研究日期；沒有足夠官方基本面時，仍可列有有效量價的「技術研究候選」，但不宣稱已驗證高成長。

## 套用與驗收

1. 比對目前 GitHub `main` 的已部署檔案，備份使用者資料與現存 Secrets。此包是**H146 基礎+H153 累積覆蓋**，若 `main` 另有較新修改必須合併差異，不可整包抹除。
2. 依 ZIP 相對路徑將修改的 Python、workflow、測試與工具複製到專案根目錄，**不要**移除未列出的任何資料庫、JSON、使用者設定、Secrets 或 `runtime-data`。
3. 執行 `python tools/h153_verify_deploy.py --root .`，再執行 `pytest -q tests/test_h153_growth_technical_ranking.py tests/test_h153_real_excel_ranked.py`。
4. 重新掃描**本輪**交易日股票，建立主管 Excel：檢查 `01_具名強勢研究` 排名及 EPS/PE/月營收來源；`03_五檔研究計畫` 名次；`00_H126主管決策` 是否完全相同。使用 Microsoft Excel 實際開啟，確認不跳「需要修復」，12 張及頁籤顏色正確。
5. 下一輪以 T+1/T+5/T+10/T+20 按**訊號日封存與次日可成交性**做外樣本績效、含交易成本與錯誤率校準，才評估排名分數是否有真實報酬優勢。

## 已知限制

本次是程式與離線測試，**不是** Streamlit Cloud 正式部署或持續資料來源驗收；若 H115 PIT 帳本仍缺財報資料、H114 K 線舊或 H109 否決很多股票，A 級可能為 0、主榜可能沒有正式推薦。系統應明確揭露原因，不可強湊股票或宣稱勝率提升。
