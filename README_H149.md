## 問題與修正

前版 H148.3.1 可召回研究股票，但缺乏主管能直接使用的研究計畫：當日有效參考價、上／下風險區間是否有根據、為何成立／失效、新聞發布日期、跨族群集中、歷史策略績效以及實際交易紀律。H148.3.1 也曾發生部署缺少 `godpick_h1482_source_audit`，故本次提供 **累積依賴包**。

本版在現有第7頁保留 H109、H113、H123、H124、H126 風控與 H145 同輪母體保護：

1. 從 H148.3 **本輪診斷池已驗的具名量價研究線索**，依資料完整、H109風險、H123/H124證據、可核對價位及量能決定研究順序（不是宣稱勝率）；考慮候選族群分散，絕不湊5檔。
2. 交易研究：有效成交額、張數、量比、突破或續攻、H109反證、失效條件、交易日與來源。正式交易權威仍是 H126，不自動升級。
3. H114 原本已有有效日線，但沒有同日的命名收盤價欄位。新增 `H114當日收盤價`，僅 `VALID_OHLCV` 且成交量單位明確、K線日期為研究當日才作研究價。支撐／壓力若未提供**同股已核數據**，不得計算目標／停損／RR。這不是成交報價。
4. 新聞只接收股票列中的**有日期、標題、來源**的資訊，不猜新聞漲幅或市場尚未反映情況；不主動加 API 請求。
5. 策略績效沿用 H129 真實可核的 T+1 **研究回放**有效樣本／總樣本，嚴格註明不是成交勝率；完整回測須有足夠 OHLCV、交易成本、無前視偏差、樣本外日期。未提供真實已平倉交易時不得虛構交易日誌或個人行為偏誤。
6. 風險：列出候選族群集中度，但**不冒充使用者真實投資部位**。沒有實際持股比例及回報序列時，不宣稱計算出 -20% 壓力情境或個股間相關係數。
7. 完成六維重點摘要＋3條流程紀律，H149 最多5檔優先研究，且只在既有 Excel 第一張表中附加，不新增工作表，第二張 `00_H126主管決策` 完全保持不變。

## 操作

1. 先和目前 GitHub `main` 實檔比較差異。**不可用舊 H146 整包直接取代已部署程式**。若 main 已有新修改，需合併後才提交。
2. 一次性將本 ZIP 10 個正式程式檔按相對路徑合併到 GitHub repo 根目錄；勿多加一層資料夾。
3. 執行 `python tools/h149_verify_deploy.py --root .`，須 PASS，再執行 `python -m pytest -q tests`。
4. 部署後進第7頁重新掃描最新交易日，點「建立主管研究 Excel」；應可下載 `StockPick_H149_TradeResearch_YYYYMMDD_HHMMSS.xlsx`，仍為2張表，第一張有 H149 六維與具名五檔研究段、第二張 H126 保持原權威。
5. 回核 H114 行情日期、成交額、有效量比、H145 母體簽章及 H109/H123/H124 資料時點。若缺證而研究0檔，不能宣稱全市場沒有機會。
