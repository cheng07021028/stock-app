2. W 非交易核查：獨立核查順位，先排除 A/B 已有股票；全部標「禁止買進」，絕不補 H126 名單。
3. 原 H148.1 工作表舊欄位、原有自動篩選及資料**完整保留在兩榜下方**，只因新資訊插入而移動位置。原主管凍結 D8 和12張分類工作表順序不變。
4. 第二張 H126 原始欄位、股票授權紀錄**不修改**。正式授權為 0 時，僅在原表下方添加醒目「0 檔／禁止買進」及認證不足說明；如果原本有授權股票，既有資料不動。
5. 匯出內建雙重內容驗收：建立首頁資料時檢查有候選必有可見的 Table，全部12張寫完後再核對首頁具名代碼與 `01_具名強勢研究` 的真實儲存格。股票池有候選而首頁空白／跨表不一致，直接拒絕將報表視作成功匯出。
