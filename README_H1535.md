## 修改（增量，不改正式交易權威）

1. 增 `godpick_h1535_research_recovery.py`，修復同輪完整研究資料的 ETF 單列誤阻：來源必須為同輪簽章，同股 H114 重疊欄位不得衝突，重複股票整體隔離而不挑有利列；同輪限量資料中的 H114 欄位可補齊對應股票，但新加入且缺實際 K 線者仍缺證、不入榜。
2. H153.5 在「開始／重新推薦」時綁定完整診斷池的 scan signature；本輪 Excel 優先使用同簽章的完整診斷池進行研究；舊版資料沒有簽章時須重新掃描，不會借用前一輪／舊快取。
3. 即使 H153 主研究榜 0 股，也可從當輪有日期且有效根數 ≥60、當日與 20 日均成交額各 ≥1.5 億、成交量 ≥500 張、量比 ≥0.55，且具有實際技術觀察事實的股票建立 **「非交易補證優先榜」**。這只是核查次序，**不會產生 H153 正式研究排名、H126 買進資格、隔日上漲機率、數值目標價**。
4. `01_具名強勢研究` 保留正常研究排名，僅追加不重複的 W 級非交易核查列；`00_主管重點觀察榜` 提示最多五檔非交易補證代號；`02_研究召回統計` 記錄恢復狀態、實際母體與核查排除原因；`03_五檔研究計畫` **不會**拿明確 `FADE_VETO` 的 C 級股票補滿五檔。**全部 12 張 Excel 與四張彩色頁籤保留。**
5. 大盤不同日、官方基本面缺 PE/EPS/三率、非法重複資料都會明確保留缺口；不因想要「至少幾檔」就降低正式風控。

```bash
python tools/h1535_verify_deploy.py --root .
python -m pytest -q tests/test_h1535_zero_recommendation_recovery.py tests/test_h1535_real_excel_nontrade.py
```

安裝後重新執行一次**完整掃描**，再產生主管 Excel；觀察 `02_研究召回統計` 中 H153.5 母體狀態，`01_具名強勢研究` 可見經證據核查的非交易候選，`00_H126主管決策` 的 0 正式授權不得被改寫。若新輪沒有有效同日成交和技術證據，即使修正後也可以保持 0，不偽造候選。
