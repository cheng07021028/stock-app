# V191-H153.4｜三率三升 × 季度獲利突破 × 官方 PIT 證據

## 一、修改原則

以 H153.3 累積程式為唯一程式基準，只新增研究條件／獲利品質證據，**不調整 H126 買進權威、H109 正式否決、推薦歷史、個人設定、Secrets**，不刪除任何頁面。保留 12 張 Excel 表、四張彩色頁籤與 H151.2 凍結視窗修復、H153.3 自動排程防卡。

## 二、條件（官方財報；不保證股價突破）

- 毛利率 = 營業毛利 / 營收；營益率 = 營業利益 / 營收；稅後淨利率 = 稅後純益 / 營收，均為單季 **百分比**，不是金額或累計%。
- 核心「三率三升」：**最近兩個相鄰季度**，各項毛利率、營益率、淨利率均嚴格大於各自去年同季（共 6 項 YoY 比較）。最近單季營益率與淨利率需正值。季增另行揭露，不與同比混用。
- 「獲利突破」：已符合上述認證，且最近單季的**毛利率與營益率**都大於前四季各自最高值（5 季內新高）。另外標記箱型技術突破是否與財報改善共振，不能單獨當成正式買進。
- H153 研究分：三率連兩季同比改善加 8 分，毛利與營益五季高點加 4 分（共最多 12），不取代 H153/H153.2 原有因子，不提高 C 級否決股交易權限；僅已驗證資料可加分。缺任何 PIT 證據：空值／待補，不假造股價預測、EPS、財報。
- 研究時點：財報僅以最早**實際公布**或**首次觀測**時間進入研究。官方每日快照若首次於今天取得，不能回填成當時已公布的歷史證據。上櫃／金融／保險／金控等會計分類不同時，不套用一般業毛利率定義。
