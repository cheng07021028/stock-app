H190 不是把舊推薦表重新排名。資料按日期抓整個市場，最多48個市場日資料請求/輪（24個雙市場日期等價），另有約15個月指數日期查詢。以實際指數月報日期作交易日參考，拒絕日期不符、低覆蓋、重複代號、非明確股/元單位、價量異常、零量。收盤後才收集當日，雙市場獨立封存；一市場失敗不刪另一市場有效資料。檔案以 SHA256 驗證、壓縮、不可靜默覆蓋歷史版本；同日衝突/損毀需稽核，不自動抹除。排程會逐次補抓最近250個指數交易日，並持續增量更新。不保證官方網站始終可用。GitHub Actions 需允許 contents:write。

首次安裝：
1. 先備份目前專案；將本ZIP解壓到獨立資料夾。
2. 執行 python tools/h190_preflight.py --root "D:\stock-app"
3. READY_APPLY_H190 才執行 python tools/h190_preflight.py --root "D:\stock-app" --apply
4. 同一 GitHub main commit 更新上述5個正式檔。特別留意隱藏的 .github 路徑。避免將備份目錄、測試假行情、正式紀錄或Secrets上傳。若以 GitHub 網頁提交，確認5個檔皆存在且內容一致。
5. GitHub Actions 啟用後，H190 workflow 在指定檔案 push 或排程時執行；可在 Actions 初次按 Run workflow 測試，但正常補抓不需每天人工操作。
6. 查看 workflow 日誌與 data/h190/health.json，再由第28頁 H190_BATCH_COVERAGE 查看已驗證250日進度及60日完整個股數。CLI: python tools/h190_market_archive.py inspect。若需本機測試來源，python tools/h190_market_archive.py collect --budget 24（本機資料尚未提交前不等於雲端永久保存）。

重要限制與保護：
- 250日是目標，不是已下載成果。每輪分批；不會在前台逐月大量重抓。無有效完整封存時，H187/H186 原功能仍可使用。
- 指數交易日僅為兩市場日曆交叉參照；缺交易日、停牌、新上市不補假 K 線。上市/上櫃資料分開，興櫃及其它商品不在本版覆蓋承諾。
- 原始行情未除權息還原；歷史資料回補首次觀測時點不等於歷史可取得時間。不可作已認證總報酬/歷史PIT回測，現有H116/H117/H119績效證據仍獨立保留。尚未串接H117正式績效封存的自動匯出；第10頁共用行情函式可讀H190但不等於既有57筆缺推薦日期已修復。
- H109/H126、H145、H189研究排名、推薦紀錄及Firestore不改動。無法保證每日有正式可買股票。
- 自動資料管線不是雲端部署成果。開發環境 DNS 無法連線到官方網站；真實TWSE/TPEx歷史回應與GitHub Actions首次運行需正式驗收。若端點欄位格式不同則拒絕保存並列明原因。
