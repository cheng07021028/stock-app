研究方式：
1. H194 既有不可覆寫訊號：六類策略與 H192 五個財報子池。補證觀察不當合格訊號。
2. H209 新增當日18:15後、H208完整研究條件成立的不可覆寫快照，記錄 H208 及其中 H198 階段；不是 H198 全母體歷史重跑。
3. T+1 開盤模擬進場，T+1/3/5/10/20 收盤模擬出場。缺交易日、價格、官方權息或單一價日不當有效成交。每筆1000股，手續費雙向0.1425%（最低20元），賣出稅0.3%，雙向滑價0.1%。僅為假設，無盤中撮合、整股可成交或券商實際費率認證。
4. 除息日在持有期間內，純現金股利按權息價差核對後納入應收（不等實際付款、未計個人股利稅）。除息日開盤才買入無當日配息。複雜配股／增資以官方參考價比例作研究代理，不能冒充實際持有股數／現金流／總報酬，不進入淨績效。資本事件全集尚未認證。
5. 權息資料以官方 TWSE TWT49U、TPEx exDailyQ 查詢，區間先行、單日備援、每輪最多24次請求（上限48），要求官方回應日期範圍、欄名、完整列數與唯一代號。空白回應未經驗證不能代表零權息。官方 JSON 目前未能在開發環境實際連通；正式回應格式需驗收，可能仍有缺口。保留原始封存，不自動覆寫衝突。
6. 20個非重疊訓練窗觀察、10個後續測試窗，按10窗滾動，不調參；訓練結果觀測時間必須早於測試決策。每窗候選全數有效才產生等權期末再平衡報酬。期末回撤不等同盤中組合回撤；單筆回撤按日收盤模擬清算價。個股淨損益合計為重疊策略樣本描述，非同一可執行資金組合。無虧損分母時獲利因子留空。
7. H209 不修改 H194 原始價格結果、不回填過往預測、不修改 H199/H126 權重或交易權限。
8. GitHub Actions 每日台灣23:20、07:20執行，push觸發與手動觸發。僅提交 data/h209/ 下公開研究資料。第32頁按需唯讀，無網路請求。Excel放入 Actions artifacts 保留90天；封存資料在GitHub main。若來源不足，狀態DATA_PENDING或缺口資訊，不虛構績效。
